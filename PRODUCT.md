# Product

## Register

product

## Users

Nontechnical people using a personal computer for day-to-day work. They describe a task, supply selected files and want a useful local AI workflow without learning model formats or training infrastructure. The initial team combines industrial engineering and ML/statistics/software experience.

## Product Purpose

Help people select, install, evaluate and tune open-source local models for their own tasks. The working web app creates CSV dashboards with a local model and trusted calculations. Retail reporting, prompt evaluation and experimental adapter training are separate optional workflows. Candy recognition is planned. General task support is the product direction; only implemented recipes may be advertised as supported. Hosted pages pair explicitly with the local companion.

## Brand Personality

A calm, clear and approachable working direction. Use plain language, useful progress and truthful uncertainty. Local Lab is a provisional name.

## Anti-references

Avoid a technical model-store front page, a dense terminal interface, unsupported accuracy percentages and theatrical agent chat. No decorative AI glow or jargon-heavy onboarding.

## Design Principles

1. Start with a person's task and desired output.
2. Show what setup will do before downloads or training.
3. Make data use and local/cloud boundaries understandable.
4. Explain measured tradeoffs, including when tuning did not help.
5. Reuse task recipes while leaving room for new capabilities.

## Accessibility & Inclusion

Use native controls, keyboard navigation, visible focus, text alongside status colors and reduced-motion support. Target WCAG AA contrast as an implementation baseline. Specific audience needs can be refined after the first demo.
