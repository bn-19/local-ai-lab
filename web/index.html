ON YOUR COMPUTER

Bring your own data.
Keep it close.

Pair this workspace with your local companion to process your CSV and use an installed model.

Start Local Lab on your Mac

  1. Open the Local Lab project folder in your terminal.
  2. Install the project dependencies: npm install
  3. Start the companion for this site: LOCAL_LAB_ORIGIN=https://local-lab-bn-19s-projects.vercel.app npm run dev
  4. Read your token locally: cat .local-lab/pairing-tokenEnter it in the connection form. The local workspace is also available as a fallback.
Open local workspace ↗

Requires the project source and Node 22 or later. The companion shows any additional runtime requirements.

Connect this workspace

Start the companion, then paste the pairing token it shows locally. Your browser may ask permission to reach your computer.

The token stays in memory until you disconnect or reload. CSVs travel directly to 127.0.0.1:4173, never through Vercel.

Setup may use hosted Agent Relay for coordination. The local app reports connection status and what is shared. A local folder is not an operating-system sandbox.

Pairing requires this exact website origin to be allowed by the companion.
